# ai-md-specification
AI.md is an open Markdown standard for author-maintained metadata about creative works.

Authors often publish metadata across multiple platforms, where it becomes inconsistent, incomplete, or inferred by third parties. AI.md provides a single canonical, author-maintained metadata file that both humans and software can reference.

# Getting Started

1. Read SPECIFICATION.md.
2. Copy AI.md.
3. Fill in your metadata.
4. Publish AI.md on your website.
